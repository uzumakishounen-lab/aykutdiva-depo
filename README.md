# Aykut Diva — Instagram video deposu

Bu depo, Instagram hesabı için otomatik üretilen Reels videolarını ve video motorunu barındırır.

- `engine.py` — imza tarzı (Aykut maskotu, palet, altyazı, müzik, render)
- `videos.py` — sahne senaryoları (her gün yeni videolar eklenir)
- `media/<tarih>/` — Instagram'a gönderilen videolar (GitHub Pages üzerinden herkese açık)
